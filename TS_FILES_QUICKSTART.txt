================================================================================
  TECHNICAL DETAILS
================================================================================

What are .TS files?
  - TorchScript serialized format (.ts extension)
  - Can contain TensorRT engines (hybrid mode)
  - Loadable by torch.jit.load() or torch_tensorrt.load()
  - 0.5s load time (instant compared to JIT compilation)

Why they solve 4-worker problem:
  - No runtime compilation = No cache conflicts
  - Pre-compiled kernels embedded in file
  - Each worker loads independently
  - No file locking issues

What gets compiled:
  - RAFT encoder (Conv2d feature extraction)
  - RFCNet downsampler (Conv3d downsampling)
  - ProPainter encoder (Conv2d encoding)

What stays in PyTorch:
  - RAFT correlation pyramid (dynamic ops)
  - Transformer attention (sparse ops)
  - Deformable convolution (requires plugin)

Hybrid execution:
  - Heavy Conv2d/Conv3d → TensorRT (fast!)
  - Dynamic ops → PyTorch (compatible!)
  - Best of both worlds!

================================================================================
  TROUBLESHOOTING
================================================================================

Problem: BUILD_TS_FILES.bat fails with "torch_tensorrt not found"
Fix: pip install torch-tensorrt

Problem: Compilation fails with "Dynamic control flow"
Fix: Script automatically falls back to torch.jit.trace (still works!)

Problem: .ts files not loading in workers
Fix: Check paths - should be in weights/ folder, NOT engines/

Problem: Workers still compile at runtime
Fix: Delete .torch_cache_* directories, verify .ts files exist

Problem: "CUDA out of memory" during compilation
Fix: Close other GPU programs, compile one model at a time
