  | Flag                                  | What it does                                                |
  |---------------------------------------|-------------------------------------------------------------|
  | --read-only                           | Filesystem is read-only, can't write anywhere except tmpfs  |
  | --user 10001:10001                    | Runs as non-root user                                       |
  | --cap-drop=ALL                        | Drops ALL Linux capabilities (no sudo, no raw sockets, etc) |
  | --cap-add=SYS_NICE                    | Only allows setting process priority (needed for GPU)       |
  | --security-opt no-new-privileges:true | Can't escalate privileges ever                              |
  | --tmpfs /tmp:...                      | RAM-based temp dirs, disappear on restart                   |
  | --memory=20g                          | Hard memory limit                                           |
  | --cpus=8                              | CPU limit                                                   |
  | --pids-limit=512                      | Max 512 processes (prevents fork bombs)
