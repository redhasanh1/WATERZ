STARTUP BEHAVIOR
================================================================================

OLD BEHAVIOR (before this fix):
  1. Container starts
  2. docker-entrypoint.sh runs
  3. Builds NeuFlow TRT engine (~10 min)
  4. Builds RFCNet TRT engine (~5 min)
  5. Starts Celery worker
  TOTAL: ~15 minutes before ready

NEW BEHAVIOR (after this fix):
  1. Container starts
  2. docker-entrypoint.sh runs
  3. Detects engines already exist (pre-built in image)
  4. Starts Celery worker immediately
  TOTAL: ~30 seconds to ready
